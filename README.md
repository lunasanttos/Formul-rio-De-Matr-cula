📝 Formulário de Matrícula

📖 Descrição

O Formulário de Matrícula é um projeto desenvolvido durante um curso da Rocketseat, com o objetivo de criar um formulário para desktop voltado para uma escola de educação infantil.
O layout foi pensado para ser simples, funcional e amigável, facilitando o preenchimento das informações necessárias para a matrícula.

🛠 Tecnologias Utilizadas

- HTML — Estruturação do conteúdo
- CSS — Estilização e design do formulário
